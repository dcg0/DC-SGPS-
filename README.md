## 📍 Acerca del Proyecto
**DC-SGPS** es una solución de rastreo GPS privada y optimizada, ejecutándose de forma persistente en entornos móviles Android mediante Termux, enlazada con dispositivos de telemetría y clientes móviles.

## 📱 Instalación y Configuración del Cliente

<p align="center">
  <img src="assets/instalacion.png" alt="Instalación DC-SGPS" width="100%">
</p>

Para conectar tus dispositivos al servidor DC-SGPS, descarga e instala la aplicación oficial **Traccar Client** en tu dispositivo móvil (disponible en Google Play Store). Una vez instalada, asegúrate de configurar correctamente los siguientes datos clave:
* **URL del Servidor:** Ingresa la dirección IP y el puerto de tu servidor DC-SGPS (por ejemplo: `http://<tu-ip-o-dominio>:8082`).
* **Identificador (ID / IMEI):** Introduce el identificador único con el que registrarás el dispositivo en tu panel.
* **Frecuencia de actualización:** Configura el intervalo de envío según tus necesidades de monitoreo.

## ⚙️ Características
* Servidor de rastreo autohospedado con base de datos local.
* Automatización mediante alias rápido (`sgps`).
* Conectividad en tiempo real con clientes móviles y dispositivos de rastreo.
* Control de versiones y despliegue integrado en GitHub.
